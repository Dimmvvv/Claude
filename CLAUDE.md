# Инструкции для Claude

Пользователь говорит по-русски — отвечай по-русски.

## Стиль анимаций

Любые новые анимации (появления, цифры, стикеры, графики, перебивки) делай по
`references/STYLE.md`: каскад под слова, один фокус, кадр не стоит мёртво, быстрое
появление с перелётом и мягкой остановкой, живые цифры. Это стиль и ритм, а не копия:
цвета, шрифты и фирменные элементы референсов не бери. Новые референсы (записи экрана в .zip)
разбирай покадрово (ffmpeg → листы кадров), допиши принципы в `references/STYLE.md`,
сами клипы в git не клади.

## Бренд

Всё про стиль — в `brand/README.md` и `brand/tokens.json`: цвета, сетка, плашка, шрифты
(CD Ovuer / Gilroy Medium Italic / Gilroy Regular), выделение. Цвета, шрифты и размеры сетки
бери только оттуда, свои не придумывай. Файлы шрифтов — в `brand/fonts/` (не в git).

## Видеовставки со скриншотами статей (`insert_maker/`)

Типичный запрос: пользователь присылает скриншот статьи и пишет, какое
предложение/абзац выделить и перевести. Результат — MP4 4K (проекты пользователя: 4K 30 fps, монтаж в CapCut): карточка на
фоне с сеткой, фиолетовый маркер по предложению, остальной текст гаснет,
предложение заменяется русским переводом. Подробности — `insert_maker/README.md`.

Порядок действий (не переписывай скрипт, просто запускай его):

1. Скопируй присланную картинку в `insert_maker/work/` (папка в .gitignore).
2. Найди строки и слова:
   ```bash
   cd insert_maker && python3 make_insert.py work/shot.png --detect
   ```
   Открой `work/shot_detect.png` (Read) — там номера строк `L1…` и слов под
   каждым словом. Определи начало и конец нужного предложения.
3. Переведи предложение на русский: естественно, кратко (длинный перевод
   уменьшает шрифт). Названия изданий/шоу, которые в оригинале курсивом,
   оформляй `*курсивом*`. Числа — по-русски: `$326 260`, `2013–14`.
4. Превью (быстро, 5 PNG-кадров) — обязательно посмотри хотя бы последний кадр:
   ```bash
   python3 make_insert.py work/shot.png --sel 7:5-9:-1 --ru 'перевод' --source 'Издание, «Заголовок»' --preview
   ```
   - `--sel СТРОКА:СЛОВО-СТРОКА:СЛОВО`, нумерация с 1, `-1` = последнее слово строки.
   - Несколько выделений в одном ролике: повторяй пару `--sel ... --ru ...`
     (пары по порядку), например `--sel 2:1-4:12 --ru '...' --sel 7:1-7:8 --ru '...'`.
     Выделение может заканчиваться посреди строки — хвост строки остаётся размытым.
     Для двух выделений ставь `--duration 8`.
   - Шрифт перевода `--font`: `serif` (по умолчанию, текст с засечками), `sans`
     (текст без засечек), `sans-bold` — для жирных заголовков. Подбирай под оригинал.
   - `--intro sticker` — карточка появляется как наклейка (белая кайма, «шлепок»,
     после появления стоит ровно). Используй, когда просят «наклейку»/вырезку; по умолчанию `fade`.
   - Если на скриншоте есть лишние линии/рамки у края — закрась их белым в рабочей
     копии (не обрезай вплотную к тексту, иначе пропадут поля).
   - Только выделение без замены на перевод (списки, цифры, имена): `--ru ''` для каждого `--sel`.
     Если исходник — запись экрана, бери неподвижный кадр (`ffmpeg -ss <сек> -frames:v 1`), где нет
     курсора и рамок, и обрезай плотно вокруг нужного места — так текст на карточке крупнее.
   - Листание сверху внутри карточки (когда присылают запись прокрутки страницы):
     склей длинную страницу из кадров записи (ffmpeg `fps=15`, сдвиг между кадрами —
     подбором по разнице, курсор и верхнюю строку кадра затереть), вырежи из неё окно
     вокруг нужного места и запусти на окне с `--scroll-page страница.png --scroll-y <y окна>`
     (`--scroll-from` — откуда листать, по умолчанию сверху; `--scroll-time 1.7`).
   - Фон `--bg`: `blue` (по умолчанию, наш основной), `red`, `brown`, `green`, `beige` — все с сеткой
     и плашкой «Теория Большого взрыва»; `grid-<цвет>` — без плашки. В `make_ranking.py` — поле `"bg"`.
     Пользователь говорит «на красном» → `--bg red`. Подпись «ИСТОЧНИК» сама темнеет на бежевом.
   - Плашка `--title 'Друзья'` — любое название сериала/фильма вместо «Теории Большого взрыва»
     (в `make_ranking.py` — поле `"title"`); `--title ''` — без плашки. Не задано — «Теория Большого взрыва».
     Спрашивай название, если по контексту видео другое шоу.
   - `--ru` и `--source` — ТОЛЬКО в одинарных кавычках, иначе shell съест `$326`.
   - Проверь: выделение ровно на нужном предложении, перевод целиком и без
     пропавших символов. Если скрипт пишет «перевод уменьшен до N%» и N < 75% —
     сократи перевод.
   - `--source` спроси у пользователя, если не ясно, из какого издания скриншот;
     без него подпись внизу просто не рисуется. Формат: `Издание, «Заголовок статьи»`.
     Если дана только ссылка — заголовок бери из неё (slug) и скажи об этом пользователю.
5. Рендер (~1,5 мин):
   ```bash
   python3 make_insert.py work/shot.png --sel ... --ru '...' --source '...' --out work/имя_insert.mp4
   ```
   Отправь видео пользователю через SendUserFile. Видео в git не коммить.

Если `--detect` склеил или разбил слова неправильно — выбери границы по
ближайшим правильно найденным словам; при серьёзных проблемах можно поменять
порог `gap_min` в `detect_layout`.

Нужны `numpy`, `Pillow`, `ffmpeg` (в облачной среде уже есть).

## Рейтинг/список с лицами-стикерами (`insert_maker/make_ranking.py`)

Когда выделения нужны по таймкодам закадра ("Парсонс на 6-й секунде") и/или с фото людей:
сцена описывается JSON (картинка, длительность, источник, шаги `{t, sel, face}`), формат — в
шапке скрипта, пример — `insert_maker/examples/ranking_example.json`.
- Скриншот: добавь белые поля сверху/снизу (~5–8% высоты), чтобы лица не обрезались.
- Лица: `crop: [cx, cy, r]` на фото — бери с запасом, чтобы были видны шея и плечи; проверь кругами.
- Если карточка наезжает на плашку рубрики — уменьши `card_h` (0.66–0.78).
- `python3 make_ranking.py scene.json --preview`, проверь кадры, потом без `--preview`.
