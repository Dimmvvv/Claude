# Фабрика вставок для YouTube

Анимированные вставки для монтажа (4K, CapCut): цитаты из статей с переводом, выделения,
рейтинги с лицами-стикерами.

| Папка | Что там |
|---|---|
| `insert_maker/` | скрипты рендера: `make_insert.py` (скриншот → выделение → перевод), `make_ranking.py` (список с выделениями по таймкодам и лицами) |
| `references/STYLE.md` | стиль анимаций: принципы и тайминги из любимых референсов |
| `brand/` | палитра, сетка, шрифты (файлы шрифтов не в git) |
| `CLAUDE.md` | инструкции для Claude: как собирать вставки |

Как работать: открыть сессию Claude с этим репозиторием, прислать скриншот/запись (большие — в .zip)
и написать, что выделить, перевести и на какой секунде. Готовые видео — в `insert_maker/work/` (не в git).
