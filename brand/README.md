# Бренд-ядро

Неизменная основа всех вставок. Значения — в `tokens.json`, макеты — в `reference/`.
Меняется только по прямой просьбе владельца канала.

## Цвета

| Цвет | HEX | Роль |
|---|---|---|
| бежевый | `#F8F4E9` | **базовый фон** |
| зелёный | `#0C3724` | фон перебивок/анимаций |
| синий | `#101535` | фон перебивок/анимаций |
| красный | `#421A1A` | фон перебивок/анимаций |
| коричневый | `#311C0B` | фон перебивок/анимаций |
| жёлтый | `#FCCD03` | выделение, всегда с прозрачностью 40% |

Цвет фона перебивки выбирается по необходимости (настроение, смена темы) — любой из четырёх.

## Фон

- Сетка на любом фоне: шаг 410 px (4K), первая вертикаль x=278, первая горизонталь y=260, линия 2 px.
  На тёмных фонах — белая 28%, на бежевом — чёрная 32%.
- Готовые фоны 4K:
  - `backgrounds/pill_<цвет>.png` — сетка + плашка «Теория Большого взрыва» (из настоящего синего фона,
    перекрашено под каждый цвет; пересобрать: `python3 brand/tools/make_pill_backgrounds.py`);
  - `backgrounds/grid_<цвет>.png` — только сетка (`python3 brand/tools/make_backgrounds.py`).
  - В скриптах вставок: `--bg blue|red|brown|green|beige` или `--bg grid-<цвет>`.
- **Плашка** (опционально): скруглённая обводка, внутри — название любого сериала/фильма или источник
  (`--title 'Название'`; рисуется Gilroy из `brand/fonts/`, если он там есть, иначе Inter Light).
  Левый край — на первой вертикали сетки, низ — на первой горизонтали. Шрифт — Gilroy Regular.

## Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| акцент | **CD Ovuer** (антиква) | заголовки, ключевые слова, выделения |
| пара к акценту | **Gilroy Medium Italic** | короткие слова-связки рядом с CD Ovuer («главная… сериала») |
| базовый | **Gilroy Regular** | обычный текст, подписи, плашка |

Файлы кладутся в `brand/fonts/` с именами `Gilroy-Regular.ttf`, `Gilroy-MediumItalic.ttf`, `CDOvuer-Regular.otf`
и **не коммитятся**, пока репозиторий публичный (на новом компьютере положить туда же вручную).
Скрипты берут их оттуда (плашка, подпись «ИСТОЧНИК»), а если их нет — похожие запасные.
⚠️ CD Ovuer в архиве — версия PERSONAL USE: для монетизируемого YouTube нужна коммерческая лицензия.

## Выделение

- На светлом (скриншоты, бежевый): жёлтый 40% **под** текстом, текст остаётся тёмным.
- На тёмном (перебивки): плашка = жёлтый 40% поверх фона, слово на ней — CD Ovuer светло-жёлтым (~`#FAE391`).

## Перебивка-заголовок (см. `reference/title_*.jpg`)

Крупное имя/тема — CD Ovuer прописными, цвет бежевый, 2 строки со сдвигом второй вправо;
короткие слова вокруг — Gilroy Medium Italic; одно ключевое слово — CD Ovuer на жёлтой плашке 40%.
Фон — любой из четырёх тёмных, плашка с названием сериала в левом верхнем углу.
