# insert_maker

Скрипт делает видеовставку 4K/60fps: скриншот статьи появляется карточкой на фоне,
нужное предложение выделяется фиолетовым маркером, остальной текст гаснет,
затем предложение заменяется русским переводом.

Нужно: Python 3, `numpy`, `Pillow`, `ffmpeg`. OCR не используется — строки и слова
находятся по пикселям.

## Использование

1. Найти номера строк и слов:

```bash
python3 make_insert.py shot.png --detect
```

Создаст `shot_detect.png` с номерами строк (L1, L2…) и слов.

2. Собрать видео:

```bash
python3 make_insert.py examples/adweek.png --sel 7:5-9:-1 --ru 'В октябре *Adweek* сообщил, что ...' --source 'Издание, «Заголовок»' --out out.mp4
```

- `--sel СТРОКА:СЛОВО-СТРОКА:СЛОВО` — нумерация с 1, `-1` = последнее слово строки
- `--ru` — перевод, `*курсив*`; в shell используйте одинарные кавычки (иначе `$326` пропадёт)
- `--source` — подпись «ИСТОЧНИК | …» внизу (необязательно)
- `--preview` — 5 PNG-кадров вместо видео (быстро)
- `--duration 7`, `--card-w 0.62`, `--hl-time`, `--ru-time`, `--pause`, `--dim`, `--blur`, `--bg`

Фон: `assets/bg_4k.png`. Шрифт перевода: Source Serif 4 (OFL), в `fonts/`.
