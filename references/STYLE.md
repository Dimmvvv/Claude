# Стиль анимаций — принципы из референсов

Источник: записи экрана, которые прислал владелец канала (ноябрь 2026).
- Long-form (3 записи): рейтинги-столбики, карта Европы с «пузырями» сумм, круговая диаграмма
  «Кто/Куда инвестирует?», столбик «прибыль/налоги», меловые расчёты, объекты в стеклянных пузырях поверх видео.
- Shorts (3 записи, 9:16): сетка иконок-розеток, карта напряжений, «Сделано в Москве» — сетка пузырей,
  истории предметов (мафия, раф, оливье), урбанистика Роттердама. **Тот же язык движения**, только
  вертикальный кадр и плотнее ритм — отдельно в `references/SHORTS.md`.

**Когда применять:** только когда владелец канала просит графическую или любую другую анимацию.
Приёмы отсюда (пузыри, кресты, сетки, столбики…) — это ориентир по ощущению и качеству движения,
а не набор элементов, которые надо воспроизвести. Сам по себе, без просьбы, ничего из референсов
во вставки не добавляй; готовые шаблоны референсов не повторяй. Делай своё решение под задачу.

**Берём только стиль, плавность, ритм и цепляемость. Не копируем 1 в 1:** их цвета (голубой/циан,
красно-зелёная карта), шрифты, фоны и фирменные элементы не используем. Цвета и шрифты — только наши
(`brand/`, фон-сетка синий `insert_maker/assets/bg_4k.png`, фиолетовый маркер).
Сами клипы в репозиторий не кладём (чужое видео, репозиторий публичный).

## Главное ощущение

1. **Всё приходит по очереди, под слова.** Ничего не появляется целиком одним кадром: строки, столбики,
   цифры, пузыри въезжают каскадом. Каждое новое появление — на конкретное слово закадра.
2. **Один фокус в кадре.** Остальное приглушено (затемнение/размытие/прозрачность), активный элемент — ярче.
3. **Кадр никогда не стоит мёртво.** Медленный наезд камеры (1.00→1.04 за сцену), лёгкое покачивание
   пузырей и стикеров, параллакс фона.
4. **Быстро вошло — плавно встало.** Появление 0,3–0,5 с с перелётом (overshoot) и мягкой остановкой,
   а не линейно.
5. **Цифры живые.** Суммы проявляются после того, как пришёл их элемент, и докручиваются (счётчик),
   хвост числа (тысячи) догоняет с задержкой.

## Тайминги (сняты покадрово)

| Приём | Как | Цифры |
|---|---|---|
| Рейтинг-столбики | растут слева направо каскадом, сверху вниз | шаг между строками ~0,06–0,08 с; рост строки ~0,4 с ease-out; весь список ~1,2–1,5 с |
| Подписи к столбикам | число проявляется у конца столбика, когда тот почти дорос | fade + лёгкий сдвиг, 0,2 с; дробная часть догоняет ещё ~0,2 с |
| Заголовок | печатается по буквам, подзаголовок мельче следом | ~25 букв/с, подзаголовок стартует через ~0,3 с |
| Акцент строки | градиентная «шторка» пробегает по нужному столбику | ~0,5 с слева направо |
| Пузырь/стикер | вырастает из точки с перелётом, потом покачивается | 0,4–0,6 с, overshoot ~8–12%; покачивание ±1–2°, период 4–5 с |
| Смена размера пузыря | крупно → уменьшается и «прилипает» в угол/к объекту | ~0,3 с ease-in-out |
| Плашка-тег заголовка | скошенная плашка за ключевым словом («**Кто** инвестирует?») | выезжает шторкой 0,25 с, затем слово |
| Диаграмма/сектора | сектора влетают и докручиваются на место | ~1 с на сборку, каскад |
| Столбик-доля | заполняется снизу, затем доля (30%) другим цветом | заполнение ~0,6 с, доля ~0,4 с + цифра |
| Меловые расчёты | строки «пишутся» по одной под слова | одна строка ~0,4 с |
| Перебивка | объект/цифра в пузыре поверх B-roll видео | пузырь держится 2–4 с, фон слегка двигается |

| Сетка пузырей | пузыри вырастают по одному, слева направо, сверху вниз | каждый 0,2–0,3 с с перелётом, шаг ~0,1–0,15 с; под каждым — маленькая подпись-год |
| Зачёркивание | красный крест «шлёпается» поверх объекта | 0,15–0,2 с, из 60% размера с перелётом, лёгкий поворот |
| Заголовок по словам | крупное слово печатается/проявляется синхронно с речью («СДЕЛАНО В → МОСКВЕ») | по слогам/буквам в темпе голоса |
| Проявление из размытия | слово/объект проявляется из сильного размытия и прозрачности | ~0,3 с |
| Вырезка «рваная бумага» | фото/скриншот с рваным краем и белой каймой, слегка наклонён | влетает 0,3 с, держится, наклон 2–4° |
| Человек в пузыре | говорящая голова или персонаж в круглом пузыре рядом с объектом, подпись-плашка под ним | как пузырь |
| Смена сцены | мягкое растворение одной сцены в другую или жёсткий склейка на говорящего | растворение ~0,3–0,4 с |

## Иерархия движения — в цифрах

- **Одно главное движение в кадре** (карточка влетает, маркер идёт, лицо выскакивает). Остальное в этот
  момент стоит или приглушено (~40%).
- **Вторичные** (лицо рядом с выделением, подпись, цифра) стартуют на **0,1–0,25 с позже** главного
  и проходят **50–70% его пути** (меньше масштаб/сдвиг/поворот).
- **Фоновые** (покачивание стикеров, медленный наезд камеры) — **меньше 5%** от главного движения,
  медленная синусоида, не останавливаются.
- Каскад: следующий элемент стартует, когда предыдущий прошёл 30–50% своего движения. Строго по очереди —
  выглядит роботом, всё сразу — дёшево.
- Перелёт (overshoot) только у положения и размера. **Прозрачность и цвет никогда не пружинят**, текст не
  отскакивает.

## Запрещено (конкретные «дефолты», которые выдают ИИ/шаблон)

- всё появляется одновременно;
- каждый элемент одинаково «проявляется и подъезжает снизу» (fade + slide-up на всём подряд);
- линейное движение (кроме вращения и полосок прогресса);
- текст двигается, пока его читают (на чтении — стоит; разрешён только общий медленный наезд кадра);
- свечение, неон, блики-вспышки, light leaks, частицы и «пыль» для красоты;
- фиолетово-синие градиенты, «стеклянные» плашки с размытием на всём, 3D-вращения без смысла;
- всё по центру одинаковыми блоками; угловые декоративные подписи без смысла;
- отскок с несколькими колебаниями у всего подряд (одна мягкая «пружинка» — максимум).

После каждого первого рендера: если модель всё равно использовала какой-то шаблонный приём — назови его
и допиши сюда.

## Почему это не выглядит «как ИИ» — и как держать планку

Референсы выглядят как ручной After Effects, потому что:
1. **Тайминг под голос, а не равномерный.** Появления стоят ровно на словах, паузы разной длины.
   ИИ-шаблон — всё через одинаковые интервалы. → Всегда спрашивай/бери таймкоды фраз.
2. **Одна система кривых.** Везде одинаковое «быстро вошло — плавно встало», маленький перелёт
   (8–12%), никаких линейных движений и никаких «пружин» с тремя отскоками.
3. **Каскад с разносом.** Соседние элементы стартуют с шагом 0,06–0,15 с, а не одновременно.
4. **Глубина.** Мягкие тени, которые меняются при «приземлении», лёгкий блик на пузыре, размытие
   движения на быстрых перемещениях. Плоские объекты без теней выглядят сгенерированными.
5. **Настоящий материал.** Реальные фото, скриншоты, вырезанные объекты, флаги, годы — а не
   абстрактные градиенты, неон, «светящиеся частицы», шум.
6. **Сдержанность.** 2–3 цвета, один стиль подписи, один размер пузырей в сцене, всё по сетке.
   Не добавляй эффекты «для красоты» (свечение, хроматическая аберрация, глитч, вращение 3D).
7. **Подписи-якоря.** Маленькие подписи (год, имя, «создатель мафии») рядом с объектами — делают
   графику «журналистской».

Проверка перед рендером: посмотри лист кадров — если всё появилось одновременно, если что-то
движется линейно, если есть элементы без тени/без смысла — переделай.

## Параметры движения в коде

Все длительности, кривые, перелёт, задержки — в `insert_maker/motion.py` (одно место для всех
скриптов). Новые анимации берут числа оттуда; если нужен новый параметр — добавь его туда, а не
пиши число в скрипте.

**Пружина (опция).** `--motion spring` (make_insert) / `"motion": "spring"` (make_ranking): появления
карточки и лиц на «пружине с массой» вместо кривой с перелётом — чуть живее, мягкая посадка.
Затухание: 1 — без отскока, 0,7–0,85 — «дорого», 0,4–0,6 — игриво (`SPRING_CARD`, `SPRING_FACE` в
`motion.py`). По умолчанию — кривая (`ease`).

## Как переводим в наш стиль

- Пузырь = наш круглый стикер (белая кайма, тень «приподнят → прилип»), как лица в `make_ranking.py`.
  Можно вариант «стеклянного» пузыря: полупрозрачный круг с бликом сверху.
- Акцент строки = наш фиолетовый маркер (шторка слева направо).
- Цифры и подписи — шрифт и цвета из `brand/`, подпись «ИСТОЧНИК | …» внизу слева, как во вставках.
- Фон — наш синий с сеткой (или другой цвет палитры). Для наложения поверх видео — **хромакей**
  (`--bg chroma`, ровный зелёный #00B140, без теней): пользователь кеит его в CapCut и кладёт поверх любого видео.

## Хук для удержания (особенно Shorts)

- Первое движение — в первые 0,3 с кадра.
- Каждые 1,5–3 с что-то новое: элемент, цифра, смена фокуса.
- Финал сцены — «жест»: синхронный подскок всех элементов, выделение итоговой цифры, наезд.
